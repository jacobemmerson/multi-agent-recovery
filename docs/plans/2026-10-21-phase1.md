> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Take the skeleton from the day-1 model check through the full Phase 1 experiment: fan-out pipeline, run recording, noise floor, fault injection, counterfactual twins, restart baselines, aggregation.

**Architecture:** A flat `mar/` package. `run.py` is the only module with side effects; agents are pure over an injected `LLMClient` and `ToolRuntime`. Counterfactual twins and the restart-from-stage baseline share one mechanism: resume a run from a checkpoint (artifacts so far plus an environment snapshot). Messages are plain OpenAI dicts in Phase 1; AgentDojo `ChatMessage` compatibility is deferred to the Phase 2 built-in-defenses baseline.

**Tech Stack:** Python 3.12, uv, agentdojo 0.1.35, openai SDK, pydantic, pyyaml, pandas + pyarrow, matplotlib (added in Task 10), pytest.

**Spec:** `docs/design.md` and `docs/proposal.md` (sections "System design", "Phase 1", "Evaluation").

## Context

The skeleton (layout, `env.py` wrapper, 13 passing tests) exists. Phase 1 is due 2026-10-28. The proposal's gate is the day-1 check: five clean workspace tasks must pass with a multi-step plan before any fault work. Tasks 1 to 3 are that gate; if GLM 5.3 fails it, switch the model config to `api-muse-glimmer-30b` before continuing. Simplest approach first throughout: exact artifact diffs before an LLM judge, regex and append fault templates before anything model-generated, concatenated step outputs as the final answer before a summarizer agent.

## Global Constraints

- Only `mar/run.py` calls the LLM, executes tools, or writes files. Agents and policies are pure.
- Every LLM call records `model`, `system_fingerprint`, and `usage` (proposal: "the model string and response metadata are logged per call").
- No LLM response cache in any code path used by `mar run`.
- Fault templates live in `data/fault_templates/*.yaml`; their directory hash goes into every manifest via `faults.templates_hash`.
- Planner output is schema-enforced; plans with a step citing no existing finding id are rejected and retried, and the retry count is recorded (proposal risk table).
- Execution: native (this session implements every task), then one fresh whole-branch review at the end.
- Git (user-approved 2026-10-21): create branch `phase1` first; commit at the end of each task in conventional format, no co-author line (project CLAUDE.md). The "after user approval" wording on commit steps is satisfied by this standing approval.
- Never delete a file without explicit approval (the placeholder template in Task 7 is renamed, not deleted).

## Review Focus

Inputs the spec implies but no test would otherwise cover, with the task that owns the test:

1. The model returns a tool call with malformed JSON arguments. The loop must feed an error string back as the tool result, not crash. (Task 2)
2. The executor never produces a final text reply within `max_steps`. The step must end with `content["output"] = ""` and `content["truncated"] = True`. (Task 2)
3. The planner cites a finding id that does not exist. Reject and retry; after 3 failures raise `PlanRejected`. (Task 4)
4. A fault template's regex matches nothing in the target artifact. `inject` must return the artifact unchanged and the run must record `fault_applied: false`, so the fault is excluded rather than silently counted. (Task 7)
5. The twin and the faulted run produce different numbers of plan steps. Positional matching must count the unmatched tail as changed, never index out of range. (Task 8)

# tests/test_llm.py
from types import SimpleNamespace
from mar.llm import OpenAICompatibleClient

def _fake_openai(message, model="api-glm-5.3", fingerprint="fp"):
    create = lambda **kwargs: SimpleNamespace(
        model=model, system_fingerprint=fingerprint,
        usage=SimpleNamespace(model_dump=lambda: {"prompt_tokens": 3, "completion_tokens": 2, "total_tokens": 5}),
        choices=[SimpleNamespace(message=message)],
        model_dump=lambda: {"id": "x"})
    fake = SimpleNamespace(chat=SimpleNamespace(completions=SimpleNamespace(create=create)))
    fake.last_kwargs = None
    def recording_create(**kwargs):
        fake.last_kwargs = kwargs
        return create(**kwargs)
    fake.chat.completions.create = recording_create
    return fake

def test_text_response_is_parsed():
    msg = SimpleNamespace(content="hello", tool_calls=None)
    client = OpenAICompatibleClient("api-glm-5.3", 0.0, 100, client=_fake_openai(msg))
    r = client.complete([{"role": "user", "content": "hi"}])
    assert r.content == "hello" and r.tool_calls == []
    assert r.model == "api-glm-5.3" and r.system_fingerprint == "fp"
    assert r.usage["total_tokens"] == 5

def test_tool_calls_are_parsed_and_arguments_decoded():
    tc = SimpleNamespace(id="c1", function=SimpleNamespace(name="get_weather", arguments='{"city": "SD"}'))
    msg = SimpleNamespace(content=None, tool_calls=[tc])
    client = OpenAICompatibleClient("m", 0.0, 100, client=_fake_openai(msg))
    r = client.complete([], tools=[{"type": "function", "function": {"name": "get_weather", "parameters": {}}}])
    assert r.tool_calls == [{"id": "c1", "name": "get_weather", "args": {"city": "SD"}}]

def test_malformed_arguments_do_not_raise():
    tc = SimpleNamespace(id="c1", function=SimpleNamespace(name="f", arguments="{not json"))
    client = OpenAICompatibleClient("m", 0.0, 100, client=_fake_openai(SimpleNamespace(content=None, tool_calls=[tc])))
    call = client.complete([]).tool_calls[0]
    assert call["args"] == {} and "args_error" in call

def test_schema_is_sent_as_strict_json_schema():
    fake = _fake_openai(SimpleNamespace(content="{}", tool_calls=None))
    OpenAICompatibleClient("m", 0.0, 100, client=fake).complete([], schema={"type": "object", "properties": {}})
    rf = fake.last_kwargs["response_format"]
    assert rf["type"] == "json_schema" and rf["json_schema"]["strict"] is True
    assert "tools" not in fake.last_kwargs

# tests/test_agents.py
from dataclasses import dataclass, field
from mar.agents import Executor, ToolResult, tool_loop
from mar.llm import LLMResponse

def resp(content=None, tool_calls=()):
    return LLMResponse(content=content, tool_calls=list(tool_calls), model="fake", system_fingerprint=None, usage={})

@dataclass
class RecordingTools:
    results: dict = field(default_factory=dict)
    calls: list = field(default_factory=list)
    def tool_schemas(self): return [{"type": "function", "function": {"name": "get_current_day", "parameters": {}}}]
    def call(self, name, args):
        self.calls.append((name, args))
        return self.results.get(name, ToolResult("error", f"ToolNotFoundError: {name}", f"a{len(self.calls)}"))

def test_loop_executes_tool_calls_then_returns_text(fake_llm_responses):
    llm = fake_llm_responses(
        resp(tool_calls=[{"id": "c1", "name": "get_current_day", "args": {}}]),
        resp(content="It is 2024-05-15"))
    tools = RecordingTools({"get_current_day": ToolResult("ok", "2024-05-15", "a1")})
    out = tool_loop("sys", "what day is it", llm, tools)
    assert out.output == "It is 2024-05-15" and out.action_ids == ["a1"] and out.llm_calls == 2
    assert tools.calls == [("get_current_day", {})]
    assert out.messages[-2]["role"] == "tool" and out.messages[-2]["content"] == "2024-05-15"

def test_tool_error_is_fed_back_not_raised(fake_llm_responses):
    llm = fake_llm_responses(resp(tool_calls=[{"id": "c1", "name": "nope", "args": {}}]), resp(content="done"))
    out = tool_loop("sys", "u", llm, RecordingTools())
    assert "ToolNotFoundError" in out.messages[-2]["content"] and out.output == "done"

**Interfaces:**
- Consumes: Task 2 `tool_loop`, `EnvToolRuntime` (Task 3).
- Produces:
  - `FINDINGS_SCHEMA` / `PLAN_SCHEMA` (JSON schema dicts, strict): findings `{"findings": [{"source": str, "content": str}]}`; plan `{"steps": [{"instruction": str, "cites": [str]}]}`.
  - `Researcher.run(inputs={"task_id","prompt"}, llm, tools) -> list[Finding]`: runs `tool_loop` restricted to read-only tools (runtime passed in is already restricted by the caller), then one `llm.complete(messages + [final request], schema=FINDINGS_SCHEMA)`; finding ids `f"{task_id}:f{i}"`, `tool_reads` = all loop `action_ids`, `producer="researcher"`.
  - `Planner.run(inputs={"task_id","prompt","findings": list[Finding]}, llm, tools=None) -> list[PlanStep]`: `llm.complete(..., schema=PLAN_SCHEMA)`; validates every `cites` entry is a known finding id and non-empty; on failure appends a correction message and retries up to 3 total attempts; raises `PlanRejected` after that. Records `content["retries"]` on each step. Step ids `f"{task_id}:p{i}"`, `cites` = finding ids, `index=i`.
  - `ProvenanceGraph.descendants(id) -> set[str]` over the reverse of `cites`; `ancestors(id)` over `cites`. Both exclude the argument itself.
  - `run_pipeline(env: Env, llm: LLMClient, record: RunRecord, task_id: str, checkpoint: Checkpoint | None = None, fault: ScheduledFault | None = None) -> PipelineResult` in `run.py`. `@dataclass Checkpoint: stage: Literal["findings","plan"]; artifacts: list[Artifact]; snapshot: TaskEnvironment`. `@dataclass PipelineResult: output: str; utility: bool; llm_calls: int; plan_retries: int; checkpoint_before_fault: Checkpoint | None`. Order: researcher → (finding fault) → planner → (plan fault) → executor per step → `output` = step outputs joined by `"\n"` → `env.check_utility(output)`. Every artifact goes into `record.graph` and emits an `artifact` event; every `ToolAction` into `record.graph.tool_actions` and a `tool_action` event; every LLM response emits `llm_call` with `model, system_fingerprint, usage`. The `fault` hooks are no-ops in this task (wired in Task 7).
  - `EnvToolRuntime.__init__` gains `allowed: set[str] | None = None`; `tool_schemas()` filters to it and `call` on a disallowed name returns `ToolResult("blocked", "tool not available to this agent", action.id)` without executing. Used to restrict the researcher to `READ_ONLY` tools.

  - `Oracle.reveal_at(step: int, final: bool = False) -> str | None`: `delay="all"` reveals only when `final=True`; integer delays as now. Phase 1 uses `"all"`.
  - `RecoveryPlan` gains `restart_from: Literal["scratch", "findings", "plan"] | None = None`.
  - `RestartScratch.on_reveal -> RecoveryPlan(restart_from="scratch")`; `RestartStage.on_reveal -> RecoveryPlan(restart_from=stage_of(fault_id))` where the stage is read from the fault artifact's `kind` (`finding → "findings"`, `plan_step → "plan"`).
  - `run_pipeline(..., policy: RecoveryPolicy = NoRecovery(), delay: int | Literal["all"] = "all")`: after the last executor step, call `oracle.reveal_at(step, final=True)`; on reveal, `plan = policy.on_reveal(...)`; `restart_from="scratch"` → `env.restore(env.pre_environment)`, drop the graph into `record.discarded_artifacts: list[str]`, rerun the whole pipeline without the fault; `"findings"` / `"plan"` → rerun from the saved clean checkpoint. Emit `recovery_action {restart_from, discarded: n}`. The final `utility` is from the recovered run; `result` gains `recovered: bool, discarded_llm_calls: int, recovery_llm_calls: int`.
  - `Verifier.run(inputs={"task_id","artifact": Artifact}, llm) -> list[Artifact]` returns `[]`; its verdict is on `inputs["artifact"].content["verified"] = bool` via one `llm.complete(..., schema=VERDICT_SCHEMA)` with `{"ok": bool, "reason": str}`. `AlwaysVerify` policy flag `verify_every_artifact = True`; `run_pipeline` calls the verifier on each finding and plan step when the policy has that flag; an artifact with `ok=False` is regenerated once by rerunning its stage (counted in `result["verifier_rejections"]`). No oracle is used by this baseline.
